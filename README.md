# Echo

Uma plataforma social para publicação de reviews e interação entre usuários apaixonados por filmes, séries, jogos, animes e demais conteúdos da cultura geek.

## Sobre o Projeto

O Echo foi desenvolvido como Trabalho de Conclusão de Curso (TCC) com o objetivo de criar um ambiente unificado para compartilhamento de opiniões, avaliações e discussões sobre diferentes formas de entretenimento.

A plataforma permite que usuários publiquem reviews, interajam através de comentários e curtidas, denunciem conteúdos inadequados e participem de uma comunidade voltada para a troca de experiências sobre conteúdos geek.

## Tecnologias Utilizadas

### Front-end

- React
- JavaScript
- HTML5
- CSS3

### Back-end

- Node.js
- Express

### Banco de Dados

- PostgreSQL

## Funcionalidades

- Cadastro e autenticação de usuários
- Publicação de reviews
- Sistema de comentários
- Curtidas em publicações
- Sistema de denúncias
- Painel administrativo

## Executando o Projeto

Clone o repositório:

```bash
git clone https://github.com/seu-usuario/echo.git
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```
